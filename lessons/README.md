Take the lesson **before** solving that topic's problems. Say **"lesson"** (or "teach me sliding window") and Claude will teach it interactively.

Each lesson has: the idea → Go templates → signals → common mistakes → a worked example (not from our list) → a warm-up exercise (`go test`) → a quiz.
